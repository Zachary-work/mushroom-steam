These pages show the 0.4 app. Since 0.5 the app is built around rooms: a permanent room code instead of per-stream codes, several people streaming at once, a voice lounge with noise suppression, and chat. The server setup is unchanged. The guides will be refreshed; the release notes list what is new.

You'll also need a server. The app pairs through a signaling server you host. Set one up in Get started · Server (a Raspberry Pi is plenty), or try the LAN-only quick test first.

⬇ Windows (installer)

Grab mushroom-steam-Setup-X.Y.Z.exe from the Releases page and run it once. It installs for your user only (no admin prompt) and adds a Start menu and desktop shortcut. From then on the app offers newer versions itself when it starts.

⚙ Build from source (any OS)

Works on Windows, macOS, and Linux. Requires Node 18+.

git clone https://github.com/Zachary-work/mushroom-steam.git
cd mushroomSteam
npm install
npm start                 # run the app
# or build a Windows portable .exe →
npm run build:win

macOS: the first launch asks for Screen Recording permission. Windows works out of the box. If Electron's binary didn't download during npm install, run node node_modules/electron/install.js.

Per-window audio from source (Windows): needs the Visual C++ build tools + Windows SDK, then npm run rebuild. Without them the app still runs and simply falls back to system audio. See Stream audio.

▶ After you download

  1. Run the app on both PCs (the one sharing and the one watching).
  2. Point each at your server: 🌐 Server → URL + shared secret (how →).
  3. Host clicks Share my screen and sends the room code; the viewer picks Watch a friend and types it in.
